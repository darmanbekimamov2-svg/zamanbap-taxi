# Заманбап Такси — демо-нуска

## Render Static Site аркылуу жайгаштыруу
1. GitHub репозиторийиңизге `index.html` файлын жүктөңүз.
2. Render'ге кирип, **New +** → **Static Site** тандаңыз.
3. GitHub репозиторийиңизди туташтырыңыз.
4. Build Command бош калсын.
5. Publish Directory катары `.` жазыңыз.
6. **Create Static Site** басыңыз.

## Эскертүү
Бул — интерфейстин демо-нускасы. Заказдар браузердин localStorage сактагычында гана турат жана башка түзмөктөргө жетпейт. Чыныгы кызматка чыгаруу үчүн сервер/API, маалымат базасы, колдонуучуларды коопсуз текшерүү, диспетчердин корголгон кирүүсү жана О!Деньги төлөмүнүн расмий интеграциясы керек.
